Big files, moved fast, proven intact.

01

Verified, not assumed

Hashed on the server

Blit asks the server for each file's SHA-256 while the file is still in its cache, and hashes its own copy as the bytes arrive. The two have to match before the file gets its real name.

Until then it's a .blitpart. A partly written file never has its final name.

The check runs alongside the download with its own progress and time left, so a 70 GB file never sits at "verifying".

Hashed on the NAS

Copies to a Synology share are checked by sha256sum on the NAS itself, over SSH, so the result comes from the data on the NAS, not from the Mac's cache.

94% of a 1 GbE link's line rate, every file verified on the NAS.

No silent size-only checks

If a hash is interrupted, Blit doesn't settle for a matching size. Size-only checks, which you can choose in Settings for more speed, are labelled everywhere they appear, and a move deletes a source only after its copy's hash has matched.

A record of every file

Every file is recorded in the Transfer Log: size, hash, how it was verified, and when. Search it by name or SHA-256, and export it as CSV.

02

Fast across an ocean

Tuned for a server 148 ms away, where one standard SFTP connection manages about 10 MB/s. Parallel connections, pipelined reads, and a receive buffer bigger than macOS allows by default: 22.5 TB a month in about 4.7 days instead of 24.5.

Resumes anything

Each part file records which byte ranges are on disk. Quit, sleep, lose Wi-Fi, unplug the drive: the queue is kept, and each file continues from where it stopped.

Control the queue

Pause, resume, reorder, cancel, Retry Now. Downloads and drive-to-NAS copies run side by side in separate lanes. When a disk is full, the transfer waits for space instead of failing, and Blit offers to empty that drive's Trash.

Shares reconnect

When the NAS sleeps or the network drops, queued copies wait for the share, then Blit remounts it with the password macOS already saved. You don't see a dialog or need to reconnect it in Finder.

Says why it's slow

The HUD shows the round trip, the route (and warns when traffic goes over Wi-Fi while a cable is plugged in), and says when the server's disk, not the network, is the limit.

03

New downloads, fetched automatically

Blit watches a folder on your server and copies each download to your drive once it's finished, verified like everything else. You still decide what goes on to the NAS.

Watch a folder

Right-click a folder on your server and choose a destination. Each download is copied once it's finished, verified, and the original stays on the server.

With qBittorrent on the server, Blit reads its own records, so a download stuck at 43% for a month is never taken for finished. With any other client, it waits for the files to stop changing.

Download status

In a folder on your server, each item says how far its download has come and the time left, how long it's been stalled, or how long it's been seeding and at what ratio.

Measured live from the files on the server, not from records an hour old.

Review from the notification

A finished download's notification shows a still from the video, skipping black frames at the start, with Quick Look and Rename buttons. Click it and Blit opens with the file selected.

If an episode is missing from the season, the notification says so, but only after Blit has checked the drive, the NAS and the server.

While you were away

When you're back after a few hours, one notification lists what arrived and whether it's all verified, what's still downloading, and what stalled.

If nothing happened, there's no notification.

05

A native Mac app

Two panes, in tabs

Where it came from beside where it goes. F5 copies to the other pane, F6 moves, ⌘U swaps them.

Each tab keeps its own pair of folders, and shows the progress of transfers started from it. Tabs are restored when Blit opens.

Finder-style browser

Servers, drives and NAS shares in one sidebar. Newest first, search (⌘F), Get Info, Open With, undo and favorites. Drag from a name to move files, from the date to select, as in Finder.

Quick Look plays what Finder's does, MKV included once QuickLook Video is installed.

Rename N items

Replace, add or format names in bulk, with a live preview, multi-step rules and presets for your naming conventions.

Copy to / Move to

Send reviewed files to a NAS folder without dragging. A move removes each file only once its copy is verified.

Already there? Blit asks: Replace, Keep Both, Skip or Stop.

Files where they go

Blit remembers where a show's last episode or a 4K movie went, and offers that folder: Move to “Season 29”, or ⇧F6. A new season gets its folder beside the last.

Compare Panes

⌃⌘C marks every file against the other pane: only here, the same, verified there, or different. Useful as a check before a move.

06

Spec sheet

PlatformmacOS 27, Apple silicon. SwiftUI and AppKit, following the Human Interface Guidelines.
TransportSwiftNIO SSH with Blit's own pipelined SFTP v3 client. Password or ed25519 / ECDSA keys, stored in the Keychain.
VerificationSHA-256 on the server (with a hash cache), on the NAS, or by read-back, labelled by strength.
ResumeByte-range state beside each part file, a durable queue, and retries with backoff.
Watch modeLooks every 1, 2, 5 or 15 minutes. Reads qBittorrent's records over SFTP; any other client by its files.
PreviewThe system's Quick Look, including formats that Media Extensions add (QuickLook Video: MKV, WebM, AVI).
UpdatesSparkle, with EdDSA-signed releases, checked daily (or off in Settings).
TrustHost keys pinned, known_hosts honoured (hashed entries too), and a changed key refused.
PrivacyNo accounts, analytics or telemetry. Blit talks only to your servers, NAS and drives, plus a daily update check.
DistributionDeveloper ID, notarized by Apple. Free to download; support is optional.
Sourcegithub.com/banastas/Blit, MIT license. Swift 6; builds with Xcode 27, and the engine and the blit CLI with swift build.
